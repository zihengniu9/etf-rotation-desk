# PandaAI三年因子统一回测结论

## 结论先行

本轮没有发现可以直接升级为正式实盘因子的PandaAI全A因子。

唯一在开发窗口和确认窗口都保持正向的候选是成长核心：开发窗口成本后净超额+0.81%，2026确认窗口+11.48%。但剔除市值最小20%后，开发窗口净超额变为-2.16%、RankIC变为-0.0308，说明正向结果很可能主要来自小盘暴露。成长核心作为独立Alpha的证伪未通过，最终决定为 `abandon`；保留研究记录，但不升级。

趋势综合分在Panda全A裸排名中的开发窗口净超额为-20.11%。这与本地“市场门控后健康延续”平均10日收益+2.65%、胜率57.60%、盈亏因子2.29形成明显对照，证明趋势策略的有效对象不是一个静态个股总分，而是“市场门控通过后再交易特定形态”。Panda结果不否定本地趋势策略，但否定了脱离行情模式直接全A排序。

成长叠加右侧交易没有改善结果。Panda代理探针中80/20、70/30、60/40的成本后净超额分别为-5.97%、-8.44%、-12.29%；本地点时回测的70/30确认段和严格市场门控同样未通过。因此继续使用财务与趋势分离、市场模式决定是否交易的架构，不采用统一总分。

## 既有模块统一判断

| 模块 | PandaAI/本地证据 | 当前判断 |
|---|---|---|
| 趋势交易 | Panda裸排名失败；本地市场门控后健康延续10日均值+2.65%、胜率57.60% | 保留“行情门控→个股形态”，禁止全A无门控裸排 |
| 成长核心 | Panda开发和确认正向，但剔除小市值后翻负 | 不能认定独立Alpha；下一版必须做规模中性化 |
| 财务综合 `financial_score` | Panda开发-1.08%；本地主板20日样本外净超额/期+2.33% | 仅保留本地主板候选，不宣称跨股票池稳健 |
| 成长质量 | Panda探针明显负向；本地20日样本外小幅正向 | 只能做风险/质量过滤，不单独作为强排序因子 |
| 成长+右侧 | Panda权重越偏趋势越差；本地确认段和严格门控未通过 | 不采用统一分，评分与交易门控继续分离 |
| ETF轮动 | 本地自适应四分之一仓样本总收益62.16%、最大回撤-9.34%，但仅约一年且缺统一基准 | 保持独立看板，必须补基准、费用和滚动样本外 |
| 短线M/S/E/Q | 现有样本集中在2026-07-27以后；>=80分组次日收盘均值+3.34%、胜率72.7%，但基础组在多项指标更强 | 仅研究快照，尚未证明增量Alpha |
| 阶段新高板 | 60日新高组次日收盘均值1.79%，非新高基础组2.46% | 新高不能单独加分，继续作为结构证据或风险项 |
| 行业主线 | 资金流与股票角色快照，不是点时历史策略 | 尚无正式回测，不并入总分 |
| 历史资讯 | 覆盖不完整，无法形成全市场逐时点样本 | 只做证据层，不进入历史收益归因 |

ETF结果没有在本轮PandaAI中运行，因为平台股票池固定为沪深全A；行业资金流、短线竞价/连板事件、市场状态和新闻证据也不能诚实映射成普通收盘横截面公式。

## 架构调整建议

1. 行情模式继续作为第一层路由，不将市场门控乘入个股分数。
2. 趋势页只在市场门控通过时输出健康延续和缩量回踩；Panda结果证明无门控全A趋势排名不可用。
3. 成长页暂不把Panda成长核心直接上线；下一轮应在本地主板池做市值分层或行业、市值双中性化，再重新点时回测。
4. `financial_score`继续作为本地成长候选基线，但页面要标明“本地主板有效、Panda全A未确认”。
5. `gr_7030`、`gr_8020`、`gr_6040`全部保留为失败研究记录，不进入生产排序。
6. 短线M/S/E/Q优先补一年以上逐日竞价、涨停梯队、炸板和次日收益数据；当前一个月级样本不足以调权重。
7. ETF轮动补沪深300/中证全指/等权ETF池基准、真实费率及滚动样本外，之后仍独立于行业和短线主线。

本报告描述历史样本，不构成投资建议。
